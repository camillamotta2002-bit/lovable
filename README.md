# Portfólio Jornalístico — Camilla Motta

Site em React + Vite, com Cormorant Garamond e Montserrat, paleta azul-petróleo e marfim.

## Rodar localmente

```bash
npm install
npm run dev
```

## Personalizar

- Foto: em `src/main.jsx`, substitua o bloco `photo-placeholder` por uma imagem, por exemplo `<img src="/foto-camilla.jpg" alt="Camilla Motta" />`, e coloque a foto na pasta `public`.
- Reportagens: edite a lista `works` em `src/main.jsx` com links e imagens reais.
- Contato: substitua o texto provisório por seus links e e-mail quando quiser.
- Visual: cores, espaçamentos e responsividade estão em `src/style.css`.

## Lovable

Use a opção de conectar/importar repositório GitHub, se disponível na sua conta/projeto. Caso a importação direta não esteja disponível, é possível usar o código como base em um projeto React/Vite. O GitHub não publica automaticamente o site.
